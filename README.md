# Kahani

Kahani is a desktop video editor for Windows. This repository holds its installers and the
update information that installed copies of Kahani read.

## Download

**[Download Kahani for Windows](https://github.com/ahmadbilal77/Kahani-releases/releases/latest/download/Kahani-Setup-x64.exe)**
(the latest version; Windows 10 or 11, 64-bit). Every version is on the
[Releases](https://github.com/ahmadbilal77/Kahani-releases/releases) page.

The installer isn't code-signed yet, so Windows SmartScreen may stop it: choose
**More info › Run anyway**. It lets you choose the installation folder and adds desktop and
Start-menu shortcuts.

## Updates

Kahani looks for a newer version here a little after it starts, and when you choose
**Help › Check for Updates…**; it offers to download it, then to restart into it.

## Uninstalling

Uninstall Kahani from **Settings › Apps**. Your preferences, keyboard shortcuts and presets stay
in `%APPDATA%\Kahani`.
